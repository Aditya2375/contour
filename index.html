What is computed

A fully connected 2-8-8-1 network with tanh hidden layers and one output logit. Training uses stable binary cross-entropy and full-batch Adam (β₁ = 0.9, β₂ = 0.999, ε = 10⁻⁸). Xavier-uniform initialization; biases start at zero.

Java is the independent numerical reference. All 105 derivatives are checked with central finite differences, and complete weights and gradients are compared between Java and JavaScript at fixed training steps.

What the picture cannot prove

A two-dimensional slice hides 103 directions. Its shape depends on direction, scale and parameterization. A visually flat region does not establish a globally flat minimum, and low training loss does not guarantee performance on other data.

Both sets are balanced seeded synthetic moons: 128 training examples (seed 17), 256 test examples (seed 91). Test data never enters an optimizer update or the slice calculation. Inspecting test scores while changing settings still makes this an educational demonstration, not an unbiased model-selection benchmark.
